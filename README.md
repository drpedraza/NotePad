# 📝 KotlinNotePad

Una aplicación de notas sencilla desarrollada en Android Studio con Kotlin. Permite agregar, editar, eliminar y personalizar el color de cada nota. Ideal como proyecto introductorio a RecyclerView, AlertDialog y patrones básicos de diseño de Android.

## 🎯 Funcionalidades

- 📌 Agregar nuevas notas con contenido personalizado
- ✏️ Editar notas existentes
- 🗑️ Eliminar notas
- 🎨 Cambiar el color de fondo de cada nota desde una paleta de colores
- 🔁 Interfaz simple y funcional con RecyclerView

## 🧠 Tecnologías utilizadas

- Kotlin
- Android Studio
- RecyclerView
- AlertDialog
- Material Design (Floating Action Button)
- Programación Orientada a Objetos
